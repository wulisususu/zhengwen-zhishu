本机只在 LibreOffice 26.2.6 里看过版面，而且字体被替换，Word / WPS 尚未验证。

| 文件 | 内容 |
|---|---|
| `01_标准通知_正式版式.docx` | 标准通知：版头、两行标题、主送、三级层次、三线表、附件说明、落款、附注、版记。格式机检 pass |
| `02_标准通知_内部草稿.docx` | 同上，每页页眉印「内部草稿 · 未审核 · 不得作为正式公文使用」 |

注意：01 是「正式版式」的样子，不是经过审批的正式公文。接口目前不放行正式导出。

## Word / WPS 核对清单

在装有方正小标宋简体、仿宋、黑体、楷体的 Windows 机器上，用 Word 和 WPS 各打开 01、02：

1. 纸张 A4；页边距 上 37 下 35 左 28 右 26 mm（布局 → 页边距 → 自定义）。
2. 每页 22 行、每行 28 字（布局 → 页面设置 → 文档网格）。数第 2 页正文行数。
3. 发文机关标志红色小标宋、居中；发文字号「示办发〔2026〕8号」居中；红色分隔线。
4. 标题二号小标宋、居中，分两行「示例单位办公室关于开展公文格式 / 规范培训工作的通知」。
5. 主送机关顶格，后接全角冒号。
6. 层次：「一、」黑体，「（一）」楷体，编号是自动编号且连续。
7. 表 1 是三线表，表题在表上方，「合计」行与上面三项之和一致（25）。
8. 「附件：参训人员名单」左空二字；落款署名与日期右空，日期与署名居中对齐。
9. 附注在成文日期下一行，左空二字。
10. 版记在最后一页版心底部：抄送、印发机关与印发日期，三条分隔线。
11. 页码「— N —」，单页居右、双页居左。
12. 02 每页页眉有红色「内部草稿 · 未审核」标记；03 里「【待补充：…】」显示醒目。

有不符的项，请记下软件、版本和截图，以便区分是 gongwen-kit 本身的问题还是我们的转换问题。
