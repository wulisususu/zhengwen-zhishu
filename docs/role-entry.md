# 角色入口（不设登录页）

按赛事要求不做登录系统。打开系统先看到两个按钮：**起草人**、**审核人**，点哪个就进入哪条业务流程。

| 选择 | 进入 | 能做什么 |
|---|---|---|
| 起草人 | `/gov/draft` | 起草通知、保存、上传材料、提交审核、查看审核结果、导出内部草稿 |
| 审核人 | `/gov/review-center` | 审核他人送审的文稿（批准 / 退回）、维护政策库（导入、核验）；不能起草 |

页面明确写着「这是角色选择，不是身份认证」。业务页顶部显示「当前角色：××（角色入口，非身份认证）」，并有「切换角色」按钮。

## 怎么实现

- 前端：`/entry` 页（`web/src/features/gov-office/pages/RoleEntryPage.vue`）。没有会话时，任何页面都会转到这里；旧的 `/login` 链接也会转过来。
  会话失效（401）时回到 `/entry?expired=1`，提示重新选择角色。原登录页 `LoginPage.vue` 已删除。
- 后端：`POST /api/v1/gov/entry {"role": "drafter" | "reviewer"}`，公开接口（`app/gov/entry.py`）。
  返回的会话属于两个专用角色账号 `role-entry-drafter`、`role-entry-reviewer`，首次使用时自动创建。
  之后所有接口照旧走 JWT 和原有的权限检查。
- `GET /api/v1/gov/entry` 返回入口是否开启，以及两个角色的说明。
- 演示构建（`VITE_GOV_OFFICE_MODE=demo`）不连后端：按钮直接切换到对应的演示身份。

## 安全边界

因为任何能访问服务的人都能选任一角色，角色账号只拿公文业务权限：

- **永远不是管理员**：用户管理、系统设置、数据清理、升级等管理接口一律 403。
- **打不开密码登录**：密码是随机生成的，没人知道，`/auth/login` 进不去。
- **不会被引导成管理员**：库里没有管理员时，系统会把第一个账号提升为管理员（`_bootstrap_admin`）；角色账号已从这一步中排除。
- **名字保留**：`role-entry-` 开头的用户名不能注册，管理员也不能创建。
- **不接管已有账号**：同名账号如果不是对应的角色账号（例如被改成了管理员），入口返回 409，不发会话。
- 原有规则不变：草稿只给起草人自己看；审核人不能起草、不能改别人的稿；任何人都不能审核自己的文稿；批准前后端重新跑双层审校。

审核人的判定统一在 `app/gov/service.py` 的 `is_reviewer`（管理员，或角色入口的审核人）。政策库的导入和核验从「仅管理员」改为「审核人」，
与前端政策库页「审核人可维护」的现有逻辑一致。

## 需要知道的取舍

- **同一角色共用一个账号。** 所有选「起草人」的人看到的是同一批草稿；所有选「审核人」的人是同一个审核人。
  演示环境可以接受；如果要区分个人，需要真正的身份认证，那就不是这个入口能解决的了。
- **没有登录页以后，管理员没有界面入口。** 系统设置、用户管理只能用真实账号通过 API 操作。
- 关闭入口：`config.yaml` 设 `gov_entry.enabled: false`。关闭后两个按钮不可用，提示「角色入口未开启」。

## 配置

```yaml
gov_entry:
  enabled: true
```

不需要新依赖。用户表新增 `gov_role` 列，启动时自动迁移（`app/database.py`），旧数据不受影响。

## 测试

- 后端 `backend/tests/test_gov_role_entry.py`：入口、单角色账号、非管理员、密码打不开、保留名、不接管冲突账号、
  管理员引导排除角色账号、起草与审核分流、批准、政策库维护权限。
- 前端 `web/tests/gov-office/role-entry.spec.ts`：路由守卫、两个按钮进入各自流程、拒绝时不保存会话、入口关闭、会话失效提示、演示构建按角色切换身份。
- 真实浏览器 `web/tests/browser/basic-live.mjs`：真实后端加真实 JWT，从 `/` 进入角色入口，依次走完：创建、保存、
  草稿对审核人不可见、上传、提交、退回、修改、再提交、批准、导出。`policy-live.mjs`、`full-integration-live.mjs` 同样改为角色入口。
  第三个账号（「其他用户无权访问」）在只有两个角色时不存在，这项隔离改由 basic-live 的「草稿对审核人不可见」覆盖。
