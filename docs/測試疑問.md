## 2026-10-27：政策文件核驗

## 2026-10-27：政策問答的回答條件與拒答

1. 政策問答在什麼情況下才會正常回答？是否取決於政策已核驗、所選檢索範圍，以及問題與條款的相關程度？
2. 輸入「你好」也被拒答：打招呼是否應有基本回應，還是這個入口只接受具體政策問題？
3. 表示「我想了解某個政策」也被拒答：需要指定政策名稱、選中文件，或把問題問得多具體，才能得到回答？
4. 政策庫已有 101 份文件但都待核實，這是否導致目前幾乎所有政策問題都無法回答？切換到「全部政策（含待核實）」後能否回答？
5. 拒答時顯示「未找到足夠依據」，能否讓使用者清楚知道本次原因，以及下一步怎麼做？例如是文件未核驗、沒有相關條款，還是提問不夠具體？
